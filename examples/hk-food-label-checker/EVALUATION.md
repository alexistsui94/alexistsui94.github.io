测试入口：`python -m unittest discover -s tests -v`。覆盖精确与别名匹配、普通配料及未知项处理、数字开头成分名、非法 JSON、版式结果字段、运行时模型配置、繁体转换以及别名布尔标记。

## 建议的端到端评测

使用获准标签样本，由业务人员建立标准答案。样本包含清晰、低清晰度、多语言、复杂排版、复合配料及名称近似等类别。开发调试样本与最终评估样本应分开。

| 指标 | 计算或记录方式 |
| --- | --- |
| 成分提取精确率 | 正确提取的成分数 / 全部提取成分数 |
| 成分提取召回率 | 正确提取的成分数 / 标准答案成分数 |
| 知识匹配准确率 | 正确匹配数 / 已匹配数；近似匹配单独统计 |
| 校对误改与漏改 | 人工逐项判定建议，保留争议项 |
| 人工处理总耗时 | 原方式与工具辅助方式均包含检查、修正、整理时间 |
| 用户实际采用 | 使用任务数 / 适用任务数，而非登录次数 |
| 成本与失败 | 每任务模型成本、延迟、失败及重复调用次数 |

先测基线，再由业务负责人确定可接受阈值。低识别质量、未知名称和近似候选进入人工复核；不以识别成功直接认定食品或标签合规。
