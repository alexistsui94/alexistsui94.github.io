<div class="seg">
<p class="en">Most explanations of ERP / start with the acronym / and a list of modules. // By the third paragraph / everyone is nodding / and nobody could explain it / to a colleague. //</p>
<p class="zh" lang="zh-Hans">多数关于 ERP 的解释，都是从缩写和一串模块清单开始的。读到第三段，所有人都在点头，但没有一个人能把它讲给同事听。</p>
</div>

<div class="seg">
<p class="en">So let us start somewhere else: / with one order. //</p>
<p class="zh" lang="zh-Hans">所以换个起点：从一张订单开始。</p>
</div>

<h2>One order, seven things that must happen<span class="h-zh" lang="zh-Hans">一张订单，背后七件事</span></h2>

<div class="seg">
<p class="en">A shop sells a fridge. // The customer pays a deposit / and wants delivery on Saturday. // Behind that one sale, / seven things have to happen. //</p>
<p class="zh" lang="zh-Hans">一家门店卖出一台冰箱，客户付了定金，要求周六送货。这一笔生意背后，有七件事必须发生。</p>
</div>

<ol class="seg-list">
<li><span class="en">Someone checks / whether it is in stock, / and where. //</span><span class="zh" lang="zh-Hans">有人确认有没有货、货在哪个仓。</span></li>
<li><span class="en">That unit gets reserved, / so it is not sold twice. //</span><span class="zh" lang="zh-Hans">这台机器被锁住，不能卖给第二个人。</span></li>
<li><span class="en">A delivery slot is booked, / with a driver and a time window. //</span><span class="zh" lang="zh-Hans">安排送货时段，落实司机和时间窗。</span></li>
<li><span class="en">The invoice is issued, / with the right tax treatment. //</span><span class="zh" lang="zh-Hans">开出发票，税的处理要正确。</span></li>
<li><span class="en">A receivable appears, / and the deposit is offset against it. //</span><span class="zh" lang="zh-Hans">形成一笔应收，定金要冲抵进去。</span></li>
<li><span class="en">Cost of goods sold is recorded, / and inventory goes down. //</span><span class="zh" lang="zh-Hans">结转销售成本，库存减少。</span></li>
<li><span class="en">If it is under warranty, / a service record is created / for that serial number. //</span><span class="zh" lang="zh-Hans">如果带保修，这个序列号要建立服务记录。</span></li>
</ol>

<div class="seg">
<p class="en">Seven steps, / four departments, / one customer who only knows / that Saturday matters. //</p>
<p class="zh" lang="zh-Hans">七个步骤，四个部门。而客户只知道一件事：周六要送到。</p>
</div>

<div class="seg">
<p class="en">ERP is the system / where those seven steps / are one continuous record / instead of seven separate ones. // That is the whole idea. // Everything else is detail. //</p>
<p class="zh" lang="zh-Hans">ERP 就是让这七步变成一条连续的记录，而不是七份各自独立的记录。整个概念就这一句，其余都是细节。</p>
</div>

<h2>What it looks like without one<span class="h-zh" lang="zh-Hans">没有 ERP 的时候是什么样</span></h2>

<div class="seg">
<p class="en">Without ERP, / the same sale lives in four places: / the shop’s own spreadsheet, / the warehouse’s stock file, / finance’s invoice list, / and a WeChat group / where the delivery is agreed. //</p>
<p class="zh" lang="zh-Hans">没有 ERP 的时候，同一笔生意活在四个地方：门店自己的表格、仓库的库存文件、财务的发票清单，以及一个用来约送货的微信群。</p>
</div>

<div class="seg">
<p class="en">Each of those is reasonable on its own. // The problem is the edges. // The fridge was sold in the shop / and also allocated to another order / in the warehouse file, / because the two were updated / two hours apart. //</p>
<p class="zh" lang="zh-Hans">每一份单独看都合理。问题出在接缝处：同一台冰箱在门店卖了，同时又被仓库文件分配给了另一张单，因为两边更新相差两个小时。</p>
</div>

<div class="seg">
<p class="en">And then there is month-end. // Four hundred orders, / two people, / two days, / matching invoices against deliveries / against payments. // Every month. // The work is not hard. // It is just repeated forever. //</p>
<p class="zh" lang="zh-Hans">然后是月底。四百张订单、两个人、两天时间，把发票、送货单、收款一一对上。每个月都来一次。这活不难，只是永远重复。</p>
</div>

<div class="seg">
<p class="en">That is the problem ERP actually solves. // Not “efficiency” in the abstract — / the specific, boring cost / of the same data being typed / by three people / into three files. //</p>
<p class="zh" lang="zh-Hans">这才是 ERP 真正解决的问题。不是抽象的「提升效率」，而是同一份数据被三个人录进三个文件这种具体又无聊的成本。</p>
</div>

<div class="seg">
<p class="en">Module names are where most people give up. // Here is the same list / translated into what people actually do. //</p>
<p class="zh" lang="zh-Hans">模块名是大多数人放弃的地方。同一份清单，翻译成人们实际在做的事，是这样。</p>
</div>

<div class="seg">
<p class="en">Notice that none of these are new activities. // Companies did all of it before. // ERP changes where the record lives, / not what the job is. //</p>
<p class="zh" lang="zh-Hans">注意：这里面没有一件是新事情。企业以前也都做。ERP 改变的是记录放在哪里，不是工作本身。</p>
</div>

<h2>Four things people get wrong<span class="h-zh" lang="zh-Hans">四个常见的误解</span></h2>

<div class="seg">
<p class="en"><strong>“ERP is accounting software.”</strong> // Accounting is one output. // The reason finance likes it / is that the entries come from operations, / not from someone retyping them / at month-end. //</p>
<p class="zh" lang="zh-Hans">「ERP 就是财务软件。」财务只是其中一项产出。财务之所以喜欢它，是因为分录来自业务动作，而不是月底有人重新录一遍。</p>
</div>

<div class="seg">
<p class="en"><strong>“Once it is live, it fixes things.”</strong> // It does not. // A messy process / becomes a messy process / with better logging. //</p>
<p class="zh" lang="zh-Hans">「上线之后问题就解决了。」不会。混乱的流程上线之后，只是变成了有更好日志的混乱流程。</p>
</div>

<div class="seg">
<p class="en"><strong>“More modules, more value.”</strong> // Every module adds configuration, / training / and something to maintain. // Companies that buy everything at once / usually use a third of it / two years later. //</p>
<p class="zh" lang="zh-Hans">「模块越多越值钱。」每个模块都会带来配置、培训和后续维护。一次买齐的公司，两年后通常只用上三分之一。</p>
</div>

<div class="seg">
<p class="en"><strong>“It is an IT project.”</strong> // IT runs the environment. // The decisions that determine whether it works / are business decisions: / who approves, / which unit counts, / what “available” means. //</p>
<p class="zh" lang="zh-Hans">「这是 IT 项目。」IT 负责环境，但决定成败的是业务决策：谁审批、按哪个单位算、「可用」是什么意思。</p>
</div>

<h2>Cloud, on-premise, or both<span class="h-zh" lang="zh-Hans">云、本地，还是混合</span></h2>

<div class="seg">
<p class="en">This choice is mostly about / who you want to blame / when something breaks at 2 a.m. // And about cash flow. //</p>
<p class="zh" lang="zh-Hans">这个选择本质上是在决定：凌晨两点出问题时，你想找谁。以及现金流怎么安排。</p>
</div>

<ul class="seg-list">
<li><span class="en">Cloud — / someone else runs the servers; / you pay monthly / and get upgrades automatically. //</span><span class="zh" lang="zh-Hans">云：别人管服务器，按月付费，升级自动跟上。</span></li>
<li><span class="en">On-premise — / your own data centre; / more control, / and more people to keep it running. //</span><span class="zh" lang="zh-Hans">本地部署：自己的机房，控制力更强，也要更多人来维护。</span></li>
<li><span class="en">Two-tier — / a heavy system at head office, / a lighter one in small subsidiaries. //</span><span class="zh" lang="zh-Hans">双层：总部用重型系统，小型子公司用轻量版本。</span></li>
<li><span class="en">Hybrid — / some of each, / usually because of history / rather than design. //</span><span class="zh" lang="zh-Hans">混合：各用一部分，通常是因为历史原因，而不是设计出来的。</span></li>
</ul>

<div class="seg">
<p class="en">Small companies with one location / almost always go cloud now. // The interesting decisions / are in the middle: / a group with twelve entities, / some acquired, / each with its own habits. //</p>
<p class="zh" lang="zh-Hans">只有一个据点的小公司现在基本都选云。真正有难度的判断在中间那一档：一个集团有十几个主体，有些是收购来的，各自都有自己的习惯。</p>
</div>

<h2>So, in one sentence<span class="h-zh" lang="zh-Hans">那么，一句话</span></h2>

<div class="seg">
<p class="en">ERP is a shared set of records / where one business event / creates the next one automatically — / so the order, the stock, / the invoice / and the accounts / are all describing the same thing. //</p>
<p class="zh" lang="zh-Hans">ERP 是一套共享的记录：一个业务动作会自动带出下一个动作，于是订单、库存、发票和账目说的是同一件事。</p>
</div>

<div class="seg">
<p class="en">The software is the easy part. // Deciding what “sold”, “available” / and “approved” mean / is the project. //</p>
<p class="zh" lang="zh-Hans">软件是简单的那部分。真正的工作量在于：把「已售」「可用」「已审批」这几个词的含义定下来。</p>
</div>
